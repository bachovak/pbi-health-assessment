Power BI Health Assessment App

Setup guide for deploying the assessment tool and connecting it to Power BI.

Project Files

index.html — The assessment app (everything is in this single file)
google-apps-script.js — Google Apps Script code for free backend storage
SETUP-GUIDE.html — This file

Architecture Overview

The app works like this:

  1. Client opens the assessment (hosted on your website or any static host)
  2. Client enters their name, company, and answers 50 questions
  3. On submit, data is sent to a Google Sheet via Google Apps Script (free)
  4. Client can also download a CSV of their responses
  5. You connect Power BI to the Google Sheet to analyze all responses
  6. Optionally, you receive an email with CSV for each submission

Step 1: Set Up Google Sheets Backend (Free)

This creates a free API endpoint that saves assessment responses to a Google Sheet.

1 Go to script.google.com and sign in with your Google account

2 Click "New project"

3 Delete any existing code in the editor, then copy and paste the entire contents of google-apps-script.js

4 (Optional) To receive email notifications with CSV attachments, change the NOTIFICATION_EMAIL variable near the bottom of the script to your email address:

var NOTIFICATION_EMAIL = "your-email@example.com";

5 Click Deploy → New deployment

6 Click the gear icon next to "Select type" and choose "Web app"

7 Set the following:

  • Description: Power BI Health Assessment
  • Execute as: Me
  • Who has access: Anyone

8 Click Deploy, then Authorize access when prompted

Note: Google will show a "This app isn't verified" warning. Click "Advanced" → "Go to [project name] (unsafe)". This is normal for personal Apps Script projects.

9 Copy the Web app URL that appears. It looks like:
https://script.google.com/macros/s/AKfycb.../exec

Step 2: Connect the App to Google Sheets

1 Open index.html in a text editor

2 Find this line near the bottom of the <script> section:

const GOOGLE_SCRIPT_URL = "";

3 Paste your Web app URL between the quotes:

const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
Done! The app will now automatically save all assessment responses to a Google Sheet. A new spreadsheet called "Power BI Health Assessment Responses" will be created in your Google Drive on the first submission.

Step 3: Host the App

You need to host index.html on the web. Here are free options:

Option A: GitHub Pages (Recommended - Free)

  1. Create a GitHub account (if you don't have one)
  2. Create a new repository (e.g., "pbi-health-assessment")
  3. Upload index.html to the repository
  4. Go to Settings → Pages → set Source to "main" branch
  5. Your app will be live at https://yourusername.github.io/pbi-health-assessment/

Option B: Netlify (Free)

  1. Go to app.netlify.com/drop
  2. Drag and drop the folder containing index.html
  3. Your app will be live immediately with a random URL
  4. You can set a custom subdomain in site settings

Option C: Your Own Website

Simply upload index.html to your web server.

Step 4: Embed in Your Website

Add this iframe to any page on your website:

<iframe
    src="https://your-hosted-url.com/index.html"
    width="100%"
    height="800"
    frameborder="0"
    style="border: none; max-width: 900px; margin: 0 auto; display: block;"
></iframe>
Tip: Adjust the height value as needed. The app is responsive and works on mobile too.

Step 5: Connect Power BI to Google Sheets

1 Open the Google Sheet in your browser (find "Power BI Health Assessment Responses" in Google Drive)

2 Click Share and set to "Anyone with the link can view"

3 In Power BI Desktop, click Get Data → Web

4 Use this URL format (replace SPREADSHEET_ID with your sheet's ID from its URL):

https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/gviz/tq?tqx=out:csv&sheet=Responses

The SPREADSHEET_ID is the long string in your Google Sheet URL between /d/ and /edit

5 Power BI will import the data as a CSV table. Set up scheduled refresh as needed.

Alternative: You can also use the CSV download option. Each assessment generates a CSV file that can be opened directly in Power BI. Place all CSVs in a folder and point Power BI to that folder to combine them.

Data Structure

Each assessment submission produces 50 rows (one per question) with these columns:

ColumnDescription
TimestampWhen the assessment was submitted
ClientNameRespondent's full name
CompanyCompany name
EmailOptional email
CategoryIDCAT01-CAT10
Categorye.g., "Business Alignment"
PillarCoE, BI Ops, or Reporting
SubcategoryIDSUB01-SUB50
Subcategorye.g., "Objectives"
QuestionIDe.g., "BIZ01"
QuestionThe question text
Weight1-3 importance weight
Score1-5 selected score
VerbalScoreIDe.g., "BIZ01_S3"
VerbalScoreThe selected answer text
RiskScoreCalculated risk score
PriorityFix now / Plan / Accept
CommentClient's optional comment
